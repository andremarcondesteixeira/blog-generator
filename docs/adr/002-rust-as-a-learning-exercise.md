# ADR-002: Rust as a Learning Exercise

## Date
2026-03-29

## Status
Accepted

## Context
I need a project to practice and improve my Rust programming skills. Building a real tool that I actually use provides stronger motivation and better learning outcomes than isolated exercises or toy projects.

## Decision
This project is written in Rust primarily as a vehicle for training my Rust language abilities. Decisions about architecture, libraries, and patterns may favor learning value over raw productivity.

## Consequences
- **Deeper Rust fluency**: working on a real project exposes idiomatic patterns, ownership challenges, and ecosystem tooling that tutorials alone do not cover.
- **Slower initial progress**: choosing Rust over a more familiar language means some tasks take longer, which is an accepted trade-off.
- **Intentional over-engineering is acceptable when educational**: exploring a Rust feature or pattern is a valid reason to choose it, even if a simpler approach exists in another language.
